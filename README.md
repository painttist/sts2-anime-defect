# 杀戮尖塔2 娘化故障机器人
## Slay The Spire 2 Anime Defect Skin Mod

——————————

**在右侧 Release 中下载。**

解压到杀戮尖塔2的 mods 文件夹安装。

v0.1版本包含静态的角色选择界面替换，战斗和商店的模型和动画替换。计划未来推出火堆的替换和动态的角色选择界面，以及角色差分。

**Download via Releases.**
